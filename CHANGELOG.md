# Changelog

## 0.2.0

- Establish MCP Boundary as one continuing project with a single distributed `$mcp-boundary` skill, the maintained Field Guide under `guide/`, and the executable Field Lab under `lab/`.
- Rework the skill around the live MCP path: active callers and entrypoints, protocol and transport ownership, capability/effect authorization, migration retirement, source/package/runtime reconciliation, named-host evidence ceilings, and a proportional stop rule.
- Move current Guide validators outside the frozen historical `mcp-server-engineering` snapshot and add repository-local skill schema validation for author and generated packages.
- Add unified provenance, licensing, CI, behavior-evaluation cases, and deterministic packaging for the 29-file pure-skill plugin.
- Replace the public website with a four-route bilingual product and engineering-library experience, with responsive interaction checks and a portable standalone build.
- Preserve the plugin boundary: no server, app connector, authentication flow, analytics, telemetry, or runtime dependency is added.
- Do not claim comparative improvement over no-skill or the historical skill; the registered behavior comparison remains unexecuted.
